# COASTLINE · Flight

一个 Godot 4 固定翼驾驶原型：从海岛小机场起飞，飞越海岸航标，再把橙白色的 **TERN 01** 安全带回跑道。无旋翼机、无战斗、无复杂系统；以易上手的驾驶与完整起降循环为优先。

## 运行

- 使用 **Godot 4.7.2**（已验证）打开 `project.godot`，按 **F5** 运行主场景。
- 或：`godot --path .`
- 采用 Compatibility / OpenGL 渲染；无插件、无 .NET、无外部资源下载。
- 默认 1600×900，可缩放窗口；`F11` 切换全屏。

## 操作

| 按键 | 功能 |
|---|---|
| Shift / Ctrl | 增加 / 减小油门，松开后保持 |
| S / W，或 ↓ / ↑ | 抬头 / 压低机头 |
| A / D，或 ← / → | 左 / 右滚转（压坡度转弯） |
| Q / E | 左 / 右方向舵；地面为前轮转向 |
| Space | 地面轮刹 |
| C | 切换近 / 远追尾镜头 |
| H | 显示 / 隐藏飞行提示 |
| Esc | 暂停 / 继续 |
| R | 从跑道重新起飞 |
| L | 进入已对准跑道的降落练习 |
| M | 静音 / 恢复发动机声 |
| F11 | 全屏 / 窗口 |

### 第一次起飞

1. 按住 **Shift** 到 100% 油门，沿中心线加速。
2. 空速约 **100 km/h** 后，短按 **S / ↓**，轻轻抬起机头。不要一直拉满。
3. 离地后松开俯仰，飞机会进行温和配平；小幅 A / D 滚转完成转向。
4. 橙色航标为当前目标。完成 5 个航标后导航回机场；航标是可选的，直接飞行并安全降落同样能完成一趟飞行。

### 降落

可先按 **L** 练习，飞机已位于跑道进近方向。逐渐收油，保持约 **110–150 km/h**，对齐中心线并保持机翼水平。贴近跑道时短按 S 拉平，降低下降率；接地后油门归零、按住 Space 刹停。**必须在跑道上停稳**才会显示成功。两端均可降落。

速度不足时压低机头、增加油门。拉得太猛会失速；动力不能让飞机悬停。撞地、入水、重着陆、倾侧接地或冲出跑道会坠毁，R 可立即重试。

## 内容

- 原创低多边形运动飞机：螺旋桨、固定三点起落架、动态副翼/升降舵/方向舵。
- 原创海岸群岛：机场、机库、塔台、风向袋、灯塔、松林、帆船与远山。
- 最小化 HUD：空速、高度（相对机场标高）、油门、航向和目标方向。
- 跑道滑跑、起飞、巡航、可选 5 航标路线、降落/坠毁/重开、独立降落练习。
- 原创合成螺旋桨声音，可通过 `python3 tools/generate_engine_audio.py` 再生成。

## 飞行模型与范围

`flight_model.gd` 是独立的 60 Hz 确定性简化模型。世界速度独立于机头朝向；升力/阻力使用动压，升力方向垂直于气流；迎角超过临界范围会衰减升力、增加阻力。还有重力、推力、侧滑阻尼、地面摩擦、轮刹与接地判断。

为了键盘友好，俯仰与滚转有范围限制，松开输入后有温和配平/回正，机头带有风标稳定性。**这是辅助操纵的游戏原型，不是航空训练或工程仿真。** 没有风场、燃油、襟翼/收放起落架、座舱仪表、气动翼段、真实轮胎悬挂或失速尾旋模型。地形接触为高度场近似；机库、树木、船等装饰物目前没有独立碰撞体。

## 验证

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/flight_model_test.gd
godot --headless --path . --script tests/session_test.gd
godot --headless --path . --quit-after 120
```

定向测试覆盖静止、跑道内起飞、坡度转弯、无动力滑翔、禁止悬停、迎角失速/恢复、温和着陆与刹停、硬着陆、水面接触、倾侧着陆和反复重置。原生视觉验证使用 Godot 4.7.2 的 Compatibility 渲染器；性能随 GPU 和分辨率变化，软件渲染不代表独显性能。
