# COASTLINE · Flight

## GodotParty 入口

从主工程大厅创建「小游戏轮换」房间，在小游戏池勾选本包即可运行单人局。准备页确认后开始，玩法结束后进入公共结算。下文保留上游原型的玩法与开发说明。


一个 Godot 4 固定翼驾驶原型：从海岛小机场起飞，飞越海岸航标，再把橙白色的 **TERN 01** 安全带回跑道。无旋翼机、无战斗、无复杂系统；以易上手的驾驶与完整起降循环为优先。

## 运行

- 使用 **Godot 4.7.2**（已验证）打开 `project.godot`，按 **F5** 运行主场景。
- 或：`godot --path .`
- 采用 Compatibility / OpenGL 渲染；无插件、无 .NET、无外部资源下载。
- 默认 1600×900，可缩放窗口；`F11` 切换全屏。

### 战地风格的相对鼠标操纵

先在游戏画面点击一次捕获鼠标。**横向移动压坡度（滚转），纵向移动控制俯仰**；默认向下拉抬头、向上推低头。Q/E 仍控制偏航，Shift/Ctrl 仍控制油门。原来的 W/S、A/D、方向键保留，按住键盘时对应轴优先，方便持续拉杆/转弯。

这是经典相对鼠标飞行的操作思路，**不是“指哪飞哪”或把屏幕光标位置当作永久摇杆**。不再移动鼠标后，操纵量会在短时间内平滑衰减到中立；飞机仍受已有气动、配平和回正影响。过大的瞬间输入有上限，避免失控。

按 Esc 打开简洁暂停面板，可直接点击鼠标开关、反转 Y 和灵敏度 −/+，也可用 F2、I、[、]。设置在本次运行中保留（包括 R 重开），退出后恢复默认。Esc 恢复会清除旧鼠标量再捕获；切出窗口自动暂停/释放，切回后需要主动按 Esc 继续。坠毁或完成飞行会释放鼠标。

参考 EA 官方飞行控制与反转/灵敏度选项，但没有机械照搬某一代《战地》的所有键位；原有游戏键位保持兼容。研究链接见 [`doc/gp_flight_references.md`](gp_flight_references.md)。

### 第一次起飞

1. 点击画面捕获鼠标，然后按住 **Shift** 到 100% 油门，沿中心线加速。
2. 空速约 **100 km/h** 后，缓慢向下拉鼠标（默认反转 Y），或短按 **S / ↓**，轻轻抬起机头。不要一直拉满。
3. 离地后停止拉杆，飞机会进行温和配平；小幅横移鼠标或 A / D 滚转完成转向。
4. 橙色航标为当前目标。完成 5 个航标后导航回机场；航标是可选的，直接飞行并安全降落同样能完成一趟飞行。

### 降落

可先按 **L** 练习，飞机已位于跑道进近方向。逐渐收油，保持约 **110–150 km/h**，对齐中心线并保持机翼水平。贴近跑道时短按 S 拉平，降低下降率；接地后油门归零、按住 Space 刹停。**必须在跑道上停稳**才会显示成功。两端均可降落。

速度不足时压低机头、增加油门。拉得太猛会失速；动力不能让飞机悬停。撞地、入水、重着陆、倾侧接地或冲出跑道会坠毁，R 可立即重试。

## 内容

- 原创低多边形运动飞机：螺旋桨、固定三点起落架、动态副翼/升降舵/方向舵。
- 原创海岸群岛：机场、机库、塔台、风向袋、灯塔、松林、帆船与远山。
- 最小化 HUD：空速、高度（相对机场标高）、油门、航向和目标方向。
- 跑道滑跑、起飞、巡航、可选 5 航标路线、降落/坠毁/重开、独立降落练习。
- 原创合成螺旋桨声音，可通过 `python3 tools/generate_engine_audio.py` 再生成。

## 飞行模型与范围

`flight_model.gd` 是独立的 60 Hz 确定性简化模型。世界速度独立于机头朝向；升力/阻力使用动压，升力方向垂直于气流；迎角超过临界范围会衰减升力、增加阻力。还有重力、推力、侧滑阻尼、地面摩擦、轮刹与接地判断。

为了鼠标/键盘友好，俯仰与滚转有范围限制，松开输入后有温和配平/回正，机头带有风标稳定性。**这是辅助操纵的游戏原型，不是航空训练或工程仿真。** 没有风场、燃油、襟翼/收放起落架、座舱仪表、气动翼段、真实轮胎悬挂或失速尾旋模型。地形接触为高度场近似；机库、树木、船等装饰物目前没有独立碰撞体。

## 正式单人接入（G02）

正式场景由协议 SoloRound 显式注入 PartyInput 与翻译，准备阶段不启动模拟；确认开始后才接受操作，结算/取消时显式停止。正式 Esc 打开框架菜单，键盘与按钮遵守同一输入屏蔽；菜单本身不暂停计时。包内 `settings.gd` 声明可改键动作，F6 使用同一默认绑定且不增删全局 InputMap。观战端不运行本机模拟。

螺旋桨使用 `assets/propeller_cue.tres` 和固定 `EngineSound`，播放流复制循环参数；油门控制音量/音高，M 静音与协议分类音量相乘。菜单或失焦释放鼠标与残留输入；关闭菜单后点击重新捕获。正式模式的鼠标模式、反转、灵敏度仍可用声明的 F2/I/方括号动作调整；画质由协议处理实际 WorldEnvironment/Sun。

从海岸机场起飞，穿过航标并安全降落。坠机也会结束本次飞行。
